# Sales Data Analysis

A beginner-level data analysis project using Python, Pandas and Matplotlib.

## Tools Used

- Python
- Pandas
- Matplotlib

## Analysis Performed

- Total sales calculation
- Total order analysis
- Average sales calculation
- Product-wise sales analysis
- Monthly sales analysis
- Sales visualization

## Objective

The objective of this project is to analyze sales data and identify useful business insights from product and monthly sales trends.
